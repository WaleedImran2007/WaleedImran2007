**AI Research Workspace** is an AI-powered research platform built to go beyond a traditional chatbot. It explores how modern AI systems can **plan, retrieve information, use tools, maintain context, and execute multi-step workflows**.

### ✨ Highlights

* 🧠 AI workflow with **planning, execution & tool calling**
* 🔎 **RAG pipeline** with embeddings and semantic retrieval
* 📚 PDF, DOCX and audio document processing
* 🎙️ Audio transcription and timestamp-aware chunks
* 🔗 Web search, page loading and calculator tools
* 💾 Persistent memory and conversation context
* 🔍 MongoDB-based vector search and retrieval
* ⚡ Asynchronous background processing
* 🐳 Dockerized backend
* ☸️ Kubernetes deployment experiments
* 🛠️ Built with **FastAPI, React, MongoDB & modern AI tooling**

> This is currently my deepest exploration into **AI Engineering and Agentic AI systems**.
